# Licence review: bundled OPL code

## What the historical notices cover

The inherited top-level `LICENSE` preserves Thomas Zeugner's MIT notice and a separate LGPL-2.1-or-later notice attributed to Robson Cozendey. The latter refers to a **different OPL emulator from the one used today**. In the project history, [`src/resources/sound/adlib/opl3.ts` at commit `c0eea09`](https://github.com/tomsoftware/Lemmings.ts/blob/c0eea09e5e2d4127e020be65035f59d3c64b5984/src/resources/sound/adlib/opl3.ts) contains Cozendey's copyright and LGPL notice and identifies itself as a TypeScript port of his Java OPL3 emulator. The July 2019 [commit `c9f35ae`](https://github.com/tomsoftware/Lemmings.ts/commit/c9f35ae37411bdd34cb74b2c3c81a0591c1d6bb4) retained that implementation under `Cozendey/` and also introduced `DBOPL/`; [commit `c44f955`](https://github.com/tomsoftware/Lemmings.ts/commit/c44f955) subsequently removed the Cozendey implementation. The inherited notice is retained in `LICENSE` for attribution and project history; it is not a licence grant for DBOPL.

The active player imports `src/game/resources/sound/DBOPL/db-opl3.ts`. That file identifies the DOSBox Team and states **GPL-2.0-or-later**; its README calls the implementation a TypeScript port of DOSBox's `dbopl.cpp`. [DOSBox Staging's licence](https://github.com/dosbox-staging/dosbox-staging/blob/main/LICENSE) also describes the DOSBox-derived works as GPL-2.0-or-later. Preserve the individual DBOPL notices and Thomas's port attribution. The fact that the two OPL notices cover different historical implementations resolves their apparent attribution conflict; it does not make the active DBOPL code LGPL.

## Distribution and remaining review

For distributions containing DBOPL, use the GPL-2.0-or-later terms as the conservative basis for the combined build, while retaining the existing notices on the individual components. Do not describe the combined application as solely MIT or claim that the inherited LGPL notice permits DBOPL to be distributed under the LGPL. The [GPL version 2 text](../public/licenses/GPL-2.0.txt) is included alongside the existing LGPL text and project/dependency notices. The deployed site offers the application source and build inputs as `source-code.zip`, without original game files; see the README's development instructions for rebuilding.

The source archive and notices are practical measures, not a legal determination that every applicable distribution obligation has been met. Review the exact distribution, dependencies, source availability and any other obligations before relying on it as a compliance conclusion. Replacing DBOPL with a separately licensed emulator would require its own provenance, compatibility, sound-quality and performance review; it would not retroactively change the terms of previously distributed copies.

The original DOS game files are separate from the application code. They must never be committed or included in the downloadable application source. The standard build imports them locally from the player. An explicitly enabled deployment bundle can also deliver operator-supplied files; the current play site uses that option and is public. That hosting decision does not resolve any rights questions around the original assets.
